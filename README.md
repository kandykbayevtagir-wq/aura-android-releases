## Install and update

Install AURA.apk once. In AURA Settings, allow installation of app updates from AURA. Updates use the same application ID and signing certificate, preserving your library and settings. The app checks for releases at launch and automatically over Wi-Fi. Android may ask you to confirm an update.

This repository contains release binaries and update manifests only. Source code is maintained privately. The existing AURA website is a separate product and is unchanged.

Audio and imported files remain on your device. Removing the app deletes its internal library. Spatial stereo processing does not claim Dolby Atmos or head tracking.
